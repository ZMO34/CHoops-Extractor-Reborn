# Remaining risks and blockers

1. No redistribution permission for gtf2dds.exe/dds2gtf.exe was located. Matching historical hashes and successful execution do not establish a license. Public packages exclude them until documented permission or a validated replacement exists.
2. PySide/Qt package metadata declares LGPL/GPL alternatives; installed wheels supply a commercial-reference notice rather than a complete redistributable compliance bundle. Inventory notices/source routes before any public binary release. Do not fabricate permission.
3. Six sideline texture layouts are raw-export-only. CDF edits can exhaust original compression allocation: first-payload-byte logo edit needed 17,210 bytes against 17,202 and was correctly rejected; a later-byte edit fit and reparsed. Safe editing does not guarantee every same-dimension texture fits.
4. SCNE headers expose 80 parts in the inspected court scene. Validated geometry/material/UV encoding and runtime evidence are not complete; no importer or advertised OBJ export was added.
5. Arbitrary archive relocation/add/delete, long roster names, conference/prestige/appearance/palette semantics and proprietary audio codecs remain unproven. Read-only inspection preserves unknown bytes.
6. GUI is an implemented development studio, not the complete mandate: no mod package export, workspace profiles, recent-project chooser, background retry queue, direct replacement context menus, full hex/pointer tools, pan/zoom controls or model viewport. Parser and build cancellation, arbitrary safe external output roots and persistent cache acceleration remain work.
7. No RPCS3/console gameplay verification has run. The local test game remains immutable.
